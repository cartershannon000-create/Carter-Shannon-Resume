The Agentic Workflow

A team of AI agents that researches, builds, checks, and delivers finished work — while you stay in charge of every decision that matters.

Think of it like a small consulting firm. You're the client. One manager runs the project, specialists do the work, an independent reviewer checks everything, and an editor fixes only what gets flagged.

The interactive map — hover or tap anything to see what it does.

The same workflow as a simple story, start to finish.

Agent

An AI that can take actions — run tools, read files, write documents — not just chat.

Orchestrator

The agent in charge. It plans and delegates, but never does the work itself.

Subagent

A helper agent spun up for one job, then retired. Keeps the manager's head clear.

Deterministic tool

A plain script, not AI. Same input, same output — used wherever numbers must be exact.

  1. 1

    You provide the brief

    Hand over whatever you have — meeting notes, a document dump, or just a question. It doesn't need to be tidy.

    Under the hood: the orchestrator interviews you to pin down scope, then writes a structured mission brief.

  2. 2

    The team builds a framework

    Before doing any work, the team decides what data to pull, how quality will be judged, and what the final output should look like.

    Under the hood: skills define rubrics and templates; scope lives in config files so the whole mission is reusable.

  3. 3

    You confirm the approach

    Nothing heavy starts until you approve the plan. No surprises later.

    Under the hood: a human gate — scope, sources, and success criteria get explicit sign-off.

  4. 4

    The pipeline runs

    Specialists fetch real data, analyze it, and build the deliverable — coordinated by the manager, who never touches the work itself.

    Under the hood: deterministic scripts pull filings and figures; AI skills synthesize and build; the orchestrator only ever sees summaries, so its judgment stays sharp.

  5. 5

    Independent review, targeted fixes

    A reviewer who didn't build anything checks the work against the sources. An editor then fixes exactly what was flagged — nothing more.

    Under the hood: a read-only review agent produces findings; the reviser applies precise directives instead of reopening the project.

  6. 6

    You receive the output

    The finished deck, the source behind every number, and an honest list of open questions.

    Under the hood: artifacts, manifests, and unresolved items return through the orchestrator — the only agent that ever talks to you.

Why the architecture looks like this

+

Context Hygiene Above All

The manager delegates the building so its own working memory never fills with large files. It only sees summaries — which keeps its judgment sharp from start to finish.

✓

Human Gates at Every Consequence

You approve before anything that matters: the scope, the findings, and the final delivery. The AI moves fast between gates, never past them.

≡

Every Number Sourced

Figures come from real filings — Form 5500, SEC EDGAR, named source documents — pulled by exact scripts, never estimated by the AI.

⌕

Objective Quality Review

A builder can't grade its own homework. A fresh agent with no memory of the build critiques the work against the sources and the rubric.

▦

Reusable by Design

Scope lives in config files and briefs, not in code. Point the same workflow at a new target and it runs again without a rebuild.

✎

Precision Over Vague Directives

The editor only acts on exact instructions, producing clean targeted fixes instead of loops of guesswork.
