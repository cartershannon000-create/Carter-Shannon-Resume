# BUG-006 — Fix mpath href to xlink:href for SVG compliance

**Meta:** id `BUG-006` · type `bug` · surface `loopband` · priority score `3.0` · scope `UI-only` · files `product-team-loop/index.html`

## User value
As a visitor on any browser, I want the orbit pulse dot to animate, so the loop reads as a living cycle rather than a static diagram.

## Acceptance criteria
- [ ] Both `<mpath>` elements reference the orbit path via `xlink:href="#orbit"` (the spec-compliant attribute) in addition to or instead of `href`
- [ ] The root `<svg class="ringsvg">` declares `xmlns:xlink="http://www.w3.org/1999/xlink"`
- [ ] The dot still animates in Chromium (no regression); animation now also works in strict XML/older Firefox parsers
- [ ] No visual change to the path or markers

## Files it owns
- `product-team-loop/index.html` — `<svg class="ringsvg">` open tag + the two `<mpath>` at lines 459-460

## Implementation
1. On the `<svg class="ringsvg" viewBox="0 0 400 400" ...>` element, add `xmlns:xlink="http://www.w3.org/1999/xlink"`.
2. Change both `<mpath href="#orbit">` to `<mpath xlink:href="#orbit" href="#orbit">` (keep `href` for HTML5 parsers, add `xlink:href` for strict ones).

No change to path geometry or timing. Scope: `UI-only`.
