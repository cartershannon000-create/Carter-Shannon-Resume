# ENH-001 — Accessible names for orbit ring nodes

**Meta:** id `ENH-001` · type `enhancement` · surface `loopband` · priority score `2.3` · scope `UI-only` · files `product-team-loop/index.html`

## User value
As a screen-reader user, I want the orbit ring's stage buttons to announce what they are, so the loop diagram is usable without sight.

## Acceptance criteria
- [ ] Each of the 4 `.rnode` buttons (discover/prioritize/sprint/ship) has an `aria-label` naming the stage and its role (e.g. "Discover: find work and evidence")
- [ ] The `.retchip` replenish button has an `aria-label` ("Replenish and repeat: refill the backlog")
- [ ] Every decorative `.ricon` SVG and the retchip SVG has `aria-hidden="true"`
- [ ] No visual change

## Implementation
- Add `aria-label="Discover: find work and evidence"` to the n-top button; `aria-label="Prioritize: score and rank"` to n-r; `aria-label="Sprint: build, review, revise"` to n-bottom; `aria-label="Ship: what passes deploys"` to n-l.
- Add `aria-label="Replenish and repeat: refill the backlog"` to the retchip button.
- Add `aria-hidden="true"` to each `<svg class="ricon" ...>` (4 of them) and to the retchip's inner `<svg>`.
