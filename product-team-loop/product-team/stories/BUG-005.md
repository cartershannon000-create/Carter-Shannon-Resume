# BUG-005 — Fix demo tab-switch autoplay race

**Meta:** id `BUG-005` · type `bug` · surface `live-demo` · priority score `2.3` · scope `UI-only` · files `product-team-loop/index.html`

## User value
As a visitor switching tabs quickly, I want the demo not to start playing if I've already left the Demo tab, so the audio/animation doesn't run in the background.

## Acceptance criteria
- [ ] `dIntroTimer` variable declared alongside other demo state
- [ ] `show()` cancels any pending intro timer at the top before running
- [ ] Switching to demo sets a tracked timer; switching away cancels it before it fires
- [ ] No regression to normal tab switching

## Files it owns
- `product-team-loop/index.html` — `show()` function and demo state variables

## Implementation
1. Add `dIntroTimer = null` to the `let di = 0, ...` declaration.
2. At the top of `show()`, add: `if(dIntroTimer){ clearTimeout(dIntroTimer); dIntroTimer=null; }`
3. Replace `setTimeout(dPlay,400)` with: `dIntroTimer=setTimeout(()=>{ dIntroTimer=null; dPlay(); },400);`
