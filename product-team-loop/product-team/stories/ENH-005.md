# ENH-005 — Make demo timeline visibly clickable

**Meta:** id `ENH-005` · type `enhancement` · surface `live-demo` · priority score `3.0` · scope `UI-only` · files `product-team-loop/index.html`

## User value
As a visitor, I want the demo step timeline to look clickable, so I discover I can jump to any step instead of only using Play/Next.

## Acceptance criteria
- [ ] `.dt-item` shows `cursor:pointer`
- [ ] Hover gives visible feedback (the dot border or caption color shifts)
- [ ] Each timeline item is keyboard/screen-reader reachable: built with `role="button"`, `tabindex="0"`, an `aria-label` naming the step, and Enter/Space activates it
- [ ] No regression: clicking an item still pauses and jumps to that scene

## Files it owns
- `product-team-loop/index.html` — `.dt-item` CSS (line 183) + `buildTimeline()` JS (line 986)

| `.dt-dot` | exists | index.html:185 |

## Implementation
1. CSS: add `cursor:pointer` to `.dt-item` (line 183). Add a hover rule:
   `.dt-item:hover .dt-dot, .dt-item:focus-visible .dt-dot{border-color:var(--green); color:var(--green)}` and `.dt-item:focus-visible{outline:none}`.
2. JS in `buildTimeline()`: on each created item set `it.setAttribute('role','button'); it.setAttribute('tabindex','0'); it.setAttribute('aria-label','Go to step '+(k+1)+': '+s.cap);` and add a `keydown` handler firing the same `pause(); dShow(k);` on Enter/Space.

## Constraints
CSS vars only; no new color literals. Scope: `UI-only`.
